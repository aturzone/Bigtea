Write a Rust function that reads a large file in fixed-size aligned blocks and returns a checksum. It must bypass the operating system page cache, handle short reads correctly, and propagate io::Error rather than panicking. Explain how you would size the buffer for an NVMe drive, why the destination buffer's alignment matters for a direct transfer, and what happens if the file offset is not a multiple of the sector size. Then show how to parallelise it across four reader threads without allocating a new buffer per block, and describe how you would test that the parallel version returns the same checksum as the serial one on a file that is not a whole number of blocks long. Discuss the trade-off between memory-mapping the file and issuing explicit reads, and say which one gives the caller control over residency.
